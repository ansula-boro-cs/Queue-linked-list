# 🚀 Queue Using Linked List

## 📌 Project Description

This project implements a Queue data structure using a Linked List
with HTML, CSS, and JavaScript.

A Queue follows the FIFO (First In, First Out) principle.
The element inserted first will be deleted first.

This project provides an interactive webpage to perform queue operations.

## 🎯 Features

- ✅ Insert (Enqueue)
- ✅ Delete (Dequeue)
- ✅ Search an Element
- ✅ Display Queue Elements
- ✅ Interactive User Interface
- ✅ Colorful 3D Buttons
- ✅ Responsive Web Design
- ✅ Queue implemented using a Linked List

## 🧠 Data Structure

**Queue Using Linked List**

Queue follows the FIFO principle:

First In → First Out

Example:

Insert: 10, 20, 30

Queue:
10 → 20 → 30 → NULL

Delete: 10

Remaining Queue:
20 → 30 → NULL

## 🔄 Queue Operations

### 1. Insert (Enqueue)
Adds a new element at the rear of the queue.

### 2. Delete (Dequeue)
Removes an element from the front of the queue.

### 3. Search
Searches for a specific element in the queue.

### 4. Display
Displays all elements currently present in the queue.
